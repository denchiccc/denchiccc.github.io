Как работает безопасность сайта?

🛡 Могут ли посетители изменить данные на сайте в интернете?
НЕТ! GitHub Pages — это защищенный статический хостинг. Посторонний человек в интернете физически не имеет права на запись в ваш репозиторий GitHub без вашего логина и пароля от GitHub.

🔐 Для чего нужен этот логин и пароль?
Они блокируют интерфейс управления: без правильной пары «логин + пароль» посторонние не смогут открыть формы добавления проектов, редактировать описание или менять контакты.

💡 Кто может применить изменения в интернете?
Только вы, авторизовавшись в своем аккаунте GitHub и сохранив обновленный файл data.json.
